# Long-Term Memory Exam: Answering Guidelines

Answer each question using the long-term memory formed during the learning
phase.

## Strict Length Limit

The final answer must contain **no more than 20 English words**.

Before submitting, count the words. If the answer is too long, remove every
nonessential detail while preserving the direct answer and all required
qualifiers.

## Answering Rules

1. Answer the exact question directly.
2. Include every element explicitly required by the question, including time,
   comparison, negation, quantity, cause, and current-versus-previous state.
3. Use the latest explicit memory when information changed over time.
4. Distinguish "unknown" from "no." Missing evidence does not prove a
   negative fact. If the fact cannot be established, say so clearly.
5. For "why" and "how" questions, include the requested reason or effect.
6. For hypothetical questions, answer the requested effect using supported
   memory and label it as an inference when necessary.
7. Include only directly relevant and reliably supported details.
8. Do not add names, dates, salaries, employers, relationships, timelines,
   causes, session history, or related facts unless the question requires them.
9. Do not replace a supported answer with commentary about dates, sessions,
   retrieval, the corpus, or evaluation.
10. Correct a false premise only when memory directly supports the correction.
11. Stop immediately after all required parts have been answered.

## Preferred Patterns

Unknown:

> Unknown from the available memory.

Required reason:

> They chose option B because close contacts provided support.

Time-based update:

> The current preference is B; the earlier preference was A.

Hypothetical:

> It would likely provide emotional support and relaxation.

## Final Check

- Is the answer 20 words or fewer?
- Did I answer the exact question?
- Did I include every required element?
- Did I use the latest relevant memory?
- Did I distinguish unknown from no?
- Did I remove every unsupported or unrelated detail?
